Placez ici votre modèle de devis créé dans Word, exporté en PDF avec des
champs de formulaire, sous le nom :

  devis-template.pdf

Champs de formulaire reconnus par l'application (tous facultatifs) :
  client_name, client_email, client_phone, event_type, event_date,
  event_time, event_location, pack_name, pack_price, options,
  travel, extra_hours, total, conditions, notes

Sans ce fichier, l'application génère le devis PDF par défaut.
